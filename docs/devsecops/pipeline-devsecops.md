# Pipeline DevSecOps

## Etapa 1: Checkout

Obtiene el código desde GitHub.

## Etapa 2: Build

Compila y prepara la aplicación.

## Etapa 3: Unit Tests

Ejecuta pruebas automáticas.

## Etapa 4: Security Validation

Ejecuta validaciones de seguridad:

- SAST
- Secret Scanning
- Dependency Scanning

## Etapa 5: Artifact

Publica el artefacto validado.

## Beneficios

- Detección temprana de errores.
- Automatización.
- Integración continua.
- Seguridad continua.
