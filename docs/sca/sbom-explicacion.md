# SBOM - SecureBank API

## ¿Qué es un SBOM?

Software Bill of Materials (SBOM) es un inventario de todos los componentes de software utilizados por una aplicación.

## Componentes Identificados

- pytest 8.4.2
- pip-audit 2.9.0
- safety 3.6.2
- semgrep

## Beneficios

- Identificación rápida de dependencias afectadas por CVEs.
- Mayor trazabilidad de componentes.
- Apoyo a auditorías de seguridad.
- Gestión eficiente de vulnerabilidades.
