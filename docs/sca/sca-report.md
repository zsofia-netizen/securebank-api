# Software Composition Analysis (SCA)

## Objetivo

Identificar vulnerabilidades conocidas en dependencias de terceros utilizadas por SecureBank API.

## Herramientas utilizadas

- pip-audit
- Safety

## Dependencias Analizadas

- pytest 8.4.2
- pip-audit 2.9.0
- safety 3.6.2
- semgrep

## Resultado

Las dependencias fueron analizadas automáticamente durante la ejecución del pipeline CI/CD.

## Beneficios

- Identificación temprana de CVEs.
- Gestión de riesgos de terceros.
- Mayor trazabilidad de componentes.
